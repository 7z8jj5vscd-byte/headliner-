# Headliner

A music industry career simulator. Start from nothing, write songs, busk, tour the world, and become a legend.

Play it at https://7z8jj5vscd-byte.github.io/headliner-/

To install on iPhone: open the link in Safari, tap Share, then Add to Home Screen.

## Debut Dream (K-pop idol simulator)

A second game lives in `kpop/`: create your idol, survive trainee evaluations, debut with a group, chase your first music show win and steer a career all the way to contract renewal and beyond. All agencies, idols and groups are fictional.

Play it at https://7z8jj5vscd-byte.github.io/headliner-/kpop/

Features 3D idols and a dancing group stage (drag to spin), a Dream board of goals, coach-picked weekly plans, a skip-ahead button, a photocard binder and a fan chat.

It installs on iPhone the same way: open the link in Safari, tap Share, then Add to Home Screen.
