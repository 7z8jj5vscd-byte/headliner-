# Headliner

A music industry career simulator. Start from nothing, write songs, busk, tour the world, and become a legend.

Play it at https://7z8jj5vscd-byte.github.io/headliner-/

To install on iPhone: open the link in Safari, tap Share, then Add to Home Screen.

## Decades

A second game: start a band in 1965 and play one year per turn all the way to the present. Manage egos, lineup changes, breakups and reunions while the industry shifts from vinyl to cassettes, music videos, CDs, file-sharing, streaming and viral clips.

Play it at https://7z8jj5vscd-byte.github.io/headliner-/decades/

It installs on iPhone the same way (Safari, Share, Add to Home Screen).
